# 🤖 Дедлайнатор — Telegram-бот для Moodle мехмата ЮФУ

> Модель Т-800. Прибыл из будущего, в котором ты не сдал лабу.

Работает через официальный Moodle Web Services API.

## Что умеет

- 🎉 оценку поставили / поменяли / удалили
- 📚 открылся новый материал (лаба, презентация, файл, ссылка, тест…)
- 📝 открылось задание, куда нужно что-то прикрепить (с дедлайном)
- ⏰ сегодня дедлайн по несданным заданиям (утром, в `REMIND_HOUR`)
- 💀 дедлайн прошёл, а задание не сдано
- 🗓 дайджест на неделю: автоматически по понедельникам и по `/week`

Задание считается сданным, если отправлено, оценено или в черновике есть прикреплённый ответ.

Команды: `/login`, `/week`, `/check`, `/logout`, `/help`, `/cancel`.

## Запуск локально

1. Создать бота у [@BotFather](https://t.me/BotFather), взять токен.
2. ```
   python -m venv .venv
   .venv\Scripts\activate         
   pip install -r requirements.txt
   copy .env.example .env          
   ```
3. Вписать `BOT_TOKEN` в `.env`.
4. `python -m botik`

## Устройство

| Файл | Что внутри |
|---|---|
| `botik/moodle.py` | клиент Moodle API (вход через token.php + REST) |
| `botik/sync.py` | снимок состояния, сравнение с прошлым, генерация уведомлений |
| `botik/storage.py` | SQLite с шифрованием: пользователи, «уже видел», снимок заданий |
| `botik/texts.py` | все тексты бота |
| `botik/handlers.py` | команды Telegram |
| `botik/main.py` | запуск, планировщик |
